# Webseiten-Check

Diese Anwendung entsteht live beim 4. HÄRTING KI-Tag am 19.11.2026 in Berlin.
Auf der Bühne bekommt eine KI (Claude Code) einen kurzen Auftrag in Alltagssprache und baut daraus in wenigen Minuten eine fertige Webseite.

Die Seite prüft eine beliebige Webadresse: Ist alles da? Ist sie sauber aufgebaut? Findet Google sie? Und vor allem: Versteht eine KI wie ChatGPT, was die Firma macht?

- `AUFTRAG.md`: der Auftrag von der Bühne, wörtlich.
- `CLAUDE.md`: die Regeln, an die sich die KI beim Bau hält.
- `docs/index.html`: die fertige Anwendung, online unter https://beyondles-ai.github.io/webseiten-check/
